# Security Policy

## Supported Versions

We provide security updates and patches for the current major release of EnoLink:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The EnoLink team takes security seriously. If you believe you have found a security vulnerability in EnoLink, please do **NOT** open a public issue.

Instead, please report it responsibly using one of the following methods:
1. **GitHub Security Advisories:** Go to the **Security** tab of the repository and click **"Report a vulnerability"**.
2. **Private Communication:** Reach out directly to the maintainer via GitHub profile contact.

### What to Include in Your Report
To help us triage and resolve the issue quickly, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
- Any suggestions for mitigation or a patch.

### Our Response Process
- We will acknowledge receipt of your report within 48 hours.
- We will provide a timeline for assessing and addressing the vulnerability.
- Once fixed, a security release will be published and you will be properly credited in the release notes (unless you prefer anonymity).
